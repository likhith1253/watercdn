# TLE-WDN: Should this past run be reused?

Risk-controlled transfer decisions for recurring leak–pressure management in water distribution networks
(research track: Trajectory Learning Evolution, TLE).

**Problem statement.** Given a library of past evolutionary runs and a new leak scenario, decide before spending
the budget whether to warm-start from one specific past run or to start fresh, so that expected savings are
maximised while the rate of harmful transfers stays below a level α chosen by the operator.

Work in progress — see `PROJECT_PLAN.md` and `IMPLEMENTATION_STATUS.md`.
