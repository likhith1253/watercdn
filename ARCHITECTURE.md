# Architecture

```
scenario θ* ──► pair features (tiers a,b,c[,d]) ──► predictor (û_j, p̂_harm,j) ──► gate (λ, α) ──► transfer | abstain
library runs ─┘                                                                                      │
                     DE/rand/1/bin  +  EPANET 2.2 (same budget B for every method)  ◄────────────────┘
```

Only the predictor and the gate are learned. The optimiser, simulator and transfer action are fixed, so every
effect is measurable (build guide §3).

## Scripts (`scripts/`, one per phase step; all resumable and seeded)

`calibrate_weights` → `make_scenarios` → `tune_de` → `pilot` → `run_campaign` → `build_tables` →
`phase4_models` → `phase5_gate` → `phase6_baselines` → (`make_shift_scenarios`, `e4_prepare`, campaign, tables,
`phase7_shift`, `phase7_e4`) → `sensitivity` → `phase8_report`. `reproduce.py` runs them in order.

## Data flow and storage

* `data/networks/` edited `.inp` files with metadata (edits, zones, hashes); `data/scenarios/` scenario tables,
  split and pair manifests with SHA-256 hashes (committed).
* `results/<exp>/jobs/` raw job files (one per library run, reference evaluation, (target, repeat), baseline run);
  not committed, regenerated by the scripts.
* `results/<exp>/tables/*.parquet` runs, generations, curves, pairs, features, probe; every row carries
  `git_commit`, `config_hash`, seed spawn key, WNTR/EPANET versions.
* `results/<exp>/phase*/` analysis outputs (CSV/JSON, committed); `figures/` generated figures; `RESULTS.md`
  generated summary.

## Fairness and leakage guards

* Budget counted in the evaluator; every method's run is asserted to use exactly B evaluations.
* Common random numbers: one `SeedSequence(master, spawn_key=(purpose, scenario, repeat))` per (target, repeat),
  split into initial-population, DE and injection streams; no global RNG.
* Four disjoint scenario sets; sources only from the library; automated split audit; label-permutation audit;
  test targets read once in Phase 5 (date recorded in `results/e1/phase5/phase5_summary.json`).
